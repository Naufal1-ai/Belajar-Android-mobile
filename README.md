# Belajar Android Mobile (Kotlin)

Repositori ini berisi latihan belajar pemrograman mobile Android menggunakan **Kotlin** pada mata kuliah Kotlin Basic, kelas TRPL 3C, Politeknik Negeri Padang.

## Teknologi
- Kotlin
- Android Studio
- Gradle (Kotlin DSL)

## Cara Menjalankan
1. Clone repositori:
```bash
   git clone git@github.com:Naufal1-ai/Belajar-Android-mobile.git
```
2. Buka folder proyek di Android Studio.
3. Tunggu proses Gradle sync selesai.
4. Jalankan aplikasi di emulator atau perangkat Android (tombol Run).

## Catatan
- Proyek dapat dibuka di Linux maupun Windows tanpa perubahan kode.
- File lokal seperti `local.properties` tidak disertakan dan dibuat otomatis oleh Android Studio.
